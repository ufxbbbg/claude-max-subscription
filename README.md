## 价格与计费：只有月付，升级按比例补差

Max 5x 每月 **$100**，Max 20x 每月 **$200**。这是网页端订阅的美元定价，不含税，移动端订阅价格可能因应用商店平台而不同，官方也保留调整价格的权利。

几个容易踩的计费细节：

- Max 只有月付，没有年付选项，这点和 Pro、Team 不同；
- 从低档升高档立即生效，按剩余周期比例补差价；降级则要等当前计费周期结束；
- 年付 Pro 转 Max：如果年付 Pro 的剩余余额高于 Max 价格，差额会变成账户余额，抵扣以后的订阅费。前提是两次购买的账单地址一致；地址变了就得先取消 Pro、等订阅到期再重新订；
- 通过 Google Play 升级会按新套餐全额扣款，旧套餐没用完的部分折算成天数加到新周期上；
- 官方不提供标准折扣，客服也发不了优惠券，限时促销偶尔有，走官方渠道公告。

顺带提醒：市面上任何“免费 Claude Max 账号”“共享 Max key”“反向代理白嫖”基本都是坑——要么共享号随时被封，要么你的对话被路由过别人的账户，隐私风险自己扛。

## 用量上限：5 小时窗口加每周封顶，Max 也不是无限

先说机制。所有个人套餐的规则一样，只是水桶大小不同：

- 每个会话的用量按 **5 小时滚动窗口**重置，用超了等窗口翻新就行，不会被锁一整天；
- 之上还有一道**每周限额**，覆盖所有模型，每周在你账户固定的一个时间点重置——和你什么时候开始用、什么时候订阅无关；
- Max 计划对 Fable 模型另有一道单独的每周限额；按第三方指南的整理，Max 用户最多可以把每周额度的一半用在 Fable 上，不额外收费，而 Pro 上 Fable 只能走 usage credits。

每次重置的时间在 Settings > Usage 里直接能看到。

官方从不公布“能发多少条”，因为实际消耗取决于消息长度、附件大小、模型选择和思考模式。第三方测评指南给过一组估算：Pro 大约是每个 5 小时窗口 45 条 Opus 或 225 条 Sonnet；Max 5x 对应约 225 条 Opus、1125 条 Sonnet；Max 20x 约 900 条 Opus、4500 条 Sonnet。这组数字当参考线用就好，别当承诺。

另外，如果账户里有“额度重置”（limit reset）次数，可以用来把 5 小时会话限额或每周限额直接拉满。

## Max 5x 还是 Max 20x

先算一笔单价账。Max 5x 花 5 倍的钱买 5 倍的量，单条成本和 Pro 打平；Max 20x 花 10 倍的钱买 20 倍的量，单条成本直接砍半。所以从纯性价比看，20x 反而是单位用量最便宜的档——前提是你真的用得完。

按使用状态对号入座：

- 每周撞 Pro 的会话限额两三次 → Max 5x；
- 每周限额经常见顶 → Max 5x，跑几周不够再升；
- 每天跑几小时的 agentic 编程会话、仓库又大 → Max 20x；
- 5x 的量撑不到午饭 → 别犹豫，20x；
- 拿不准 → 先 5x，中途升档按比例计费，猜低了没有惩罚。

判断的核心从来不是“Claude 好不好用”，而是你撞 Pro 限额的频率。把被中断时浪费掉的时间折算一下，答案通常就出来了。

## 这几种情况，先别急着买 Max

- 只是偶尔在 Pro 上超限：开 usage credits，按标准 API 价续用，比每月多掏 80 美元划算；
- 工作以程序化调用为主：写进产品、脚本、批处理的那部分走 API 按 token 付费，大吞吐场景多半比订阅便宜；
- 瓶颈是协作而不是个人额度：Max 是纯个人方案，没有共享工作区、单点登录和管理后台，给全组一人买一个 Max 也解决不了问题，该看 Team；
- 还没量过自己的用量：先在 Settings > Usage 看一周数据，再决定。

## 撞到限额之后，你有三个选项

1. 等重置：5 小时窗口持续翻新，每周限额在固定时间归零；
2. 开 usage credits：预付一笔余额，超限后按标准 API 价继续用，可以在 Console 里设月度消费上限或开自动续充；
3. 升档：5x 不够升 20x，按剩余周期补差价。

用编程代理的话，再补两个实用细节：终端里跑 /status 能随时看剩余额度；另外，如果你的系统环境变量里设了 ANTHROPIC_API_KEY，编程代理会优先走这个 key 的 API 计费，而不是消耗订阅额度——不想被额外扣费就把它清掉，用订阅账号重新登录。
